📖 Workflow guide

1. Reception → Register a patient.
2. Fixation → Click each slide chip as you put it in fixative. Clock time = pull time.
3. Staining → Select from empty container, run protocol step by step.
4. Clear & Mount → Physically verify, then confirm each slide.
5. Scoring → Tap score buttons for Observer 1 and Observer 2.
6. Timing → Full per-patient timeline with delays and durations.
7. Data → Export CSV/JSON after each session.
